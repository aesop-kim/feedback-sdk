# 데모 녹화 대본

데모 고객사 페이지(`http://localhost:3001`)를 화면 녹화하며 말하는 내용이에요. 길이는 약 62초이고, 말하는 순간에 맞춰 해당 요소를 가리키거나 눌러요. 기대 결과는 `fixtures/demo-recording/expected.json`에 있어요.

## 대본

1. 안녕하세요. 계약서 관리 화면을 써 보다가 이상한 게 세 가지 있어서, 화면 보여 드리면서 말씀드릴게요.
2. 먼저 여기 오른쪽 위에 있는 파란 계약서 등록 버튼이요. 새 계약서를 하나 만들려고 눌렀는데, 아무 반응이 없어요. 혹시 몰라서 한 번 더 눌러 봤는데도 똑같아요. 목록 맨 위에 새 계약서가 생겨야 하는데, 개수도 그대로 육십 개예요.
3. 그다음은 표 머리글이에요. 여기 금액 칸 제목이 계약 금액이어야 하는데, 계약 긍액이라고 오타가 나 있어요. 다른 칸은 다 멀쩡한데 여기만 글자가 틀렸어요.
4. 마지막으로 맨 위에 있는 전체 계약서라는 제목이요. 이 글씨가 다른 곳이랑 좀 달라 보여요. 정확히 뭐가 문제인지는 저도 모르겠는데, 굵기가 너무 굵거나 글자 사이가 좁은 것 같아서 어색해요.
5. 정리하면 등록 버튼이 안 눌리는 것, 머리글 오타, 제목 글씨가 이상한 것 이렇게 세 가지예요. 특히 등록 버튼이 안 눌리는 게 제일 불편하니까, 그것부터 확인해 주시면 좋겠어요. 감사합니다.

## 타임라인

대사 길이는 `say -v Yuna` 실측값이에요(1번 7.7초, 2번 15.9초, 3번 11.2초, 4번 13.7초, 5번 14.0초, 합계 약 62초). 대사 사이에 0.5초씩 쉬어요.

| 초 | 동작 | 대사 |
| --- | --- | --- |
| 0-8 | 마우스를 가만히 두고 화면 전체를 보여 줌 | 1번 |
| 8.5 | `계약서 등록` 버튼에 hover | 2번 시작 |
| 13, 17 | `계약서 등록` 버튼 클릭 두 번 (목록 개수 60이 그대로임) | 2번 "눌렀는데", "한 번 더" |
| 25 | 표 머리글 `계약 긍액`에 hover | 3번 시작 |
| 37 | `전체 계약서` 제목에 hover | 4번 시작 |
| 51.5 | `계약서 등록` 버튼으로 마우스를 되돌려 hover | 5번 시작 |
| 65.5 | 녹화 종료 | 끝 |

## Playwright 동작

| 초 | 동작 | 로케이터 |
| --- | --- | --- |
| 8.5 | 버튼 hover | `page.getByRole('button', { name: '계약서 등록' }).hover()` |
| 13, 17 | 버튼 클릭 두 번 | `page.getByRole('button', { name: '계약서 등록' }).click()` |
| 25 | 머리글 hover | `page.getByText('계약 긍액', { exact: true }).hover()` |
| 37 | 제목 hover | `page.getByRole('main').getByText('전체 계약서', { exact: true }).hover()` |
| 51.5 | 버튼 hover | `page.getByRole('button', { name: '계약서 등록' }).hover()` |

`전체 계약서`는 왼쪽 메뉴에도 있으니 반드시 `getByRole('main')` 안에서 찾아요.

## 음성 만들기

대사 1~5번을 한 줄에 한 문단씩 `demo-script.txt`로 저장해 읽어요. 속도는 기본값이에요.

```bash
say -v Yuna -o demo-recording.aiff -f demo-script.txt
```
