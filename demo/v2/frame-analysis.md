# 레퍼런스 4편 프레임 분석

v2 데모 영상을 다시 만들기 위해 레퍼런스 영상 4편을 프레임 단위로 뜯어본 기록입니다. 수치는 모두 직접 측정했고, 측정이 아니라 눈으로 판단한 값에는 *(관찰)*을 붙였습니다.

## 방법

| 항목 | 방법 | 산출물 (`demo/v2/analysis/`, gitignore) |
|---|---|---|
| 컷 검출 | `select='gt(scene,0.25)'`, 모션그래픽은 연속 전환이 많아 `0.08`도 함께 돌림 | `*.cuts.txt`, `*.cuts08.txt` |
| 콘택트 시트 | 0.5초마다 1프레임, 6x5 타일, 왼쪽 위에 타임스탬프 | `<id>_sheet_NN.png` (영상당 3~6장) |
| 모션 시퀀스 | 빠른 동작 23곳을 원본 fps 그대로 10~20프레임씩 타일로 뽑음 | `seq/*.png` |
| 크기·색 | 1920x1080 원본 프레임 27장, 테두리 최빈색으로 배경 hex를 잡고 배경과 다른 픽셀의 행 범위로 줄 높이 측정 | `frames/*.png` |
| 오디오 | `ebur128`로 라우드니스, 스펙트럴 플럭스 + 빗살 필터로 BPM, 컷 시각과 박자 격자의 오차 계산 | `*.pcm` |

컷 검출기가 잡은 컷은 Marker 5개(0.25) / 28개(0.08), 토스 0 / 7, Notion 9 / 37, Jam 8 / 24개입니다. 레이아웃 이동, 스케일 인, 색 와이프처럼 연속 전환이 많아서 검출기가 놓치는 컷이 많았습니다. 그래서 아래 샷 표는 콘택트 시트와 시퀀스를 보고 사람이 나눈 "시각 비트" 기준입니다.

### 5.4 카메라

- **Marker:** 실제로 확대하는 연속 푸시를 씁니다. 커서 동작을 따라 1.9배까지 15f 동안 들어갑니다. 3D는 Y축 플립 휩에만 쓰고, 유지 시간은 2~4s입니다.

- **Jam:** 화면 녹화를 디지털 줌(1.4배, 30f)과 스크롤로 움직입니다.
- **3D 기울임:** 네 편 모두 Marker의 플립 휩 한 번과 쌓이는 카드의 2D 회전 말고는 원근 기울임을 쓰지 않습니다.

## 6. 가장 옮겨 오기 좋은 기법 12가지

1. **단어 단위 하드 팝 오프너 (Marker).** 페이드 없이 1~2f 만에 나타나고, 8f 간격으로 붙습니다. Regular(작게)와 ExtraBold(크게)를 1:3 정도로 섞어 한 문장을 2~3줄로 쌓습니다.
2. **한글 입력기식 음절 타이핑 + 파랑 깜빡임 (토스).** 음절당 2f, 새 음절은 강조색으로 4f 동안 떴다가 3f 만에 본문색으로 돌아옵니다. 한국어 카피에 그대로 쓸 수 있습니다.
3. **고정 구절 + 세로 롤링 목록 (토스).** 왼쪽 구절은 고정하고, 오른쪽 목록은 줄 간격 11.4%H로 굴립니다. 포커스 줄만 1.6배 크기에 검정, 나머지는 회색입니다. 한 줄 15f에서 2f로 가속합니다.
4. **글자 단위 스크램블 문구 교체 (토스).** 장면 사이를 페이드 대신 글자 교체(12f)로 잇습니다.
5. **배경색 반전으로 감정 전환 (Marker).** 3f 위→아래 와이프, 또는 카드 경계에서 4f 만에 퍼지는 색 와이프를 씁니다.
6. **가속하며 쌓이는 문제 카드 (Marker).** 카드 하나가 5f 만에 날아들고 회전 ±4~12°, 간격은 20f에서 8f로 줄어듭니다. 숫자 배지(7 → 999+)로 과장합니다.
7. **단색 배경 위 평면 UI 레이어 + 여백 프레이밍 (Notion, Marker).** 와이드는 사방 5~6%H 여백을 두고, 클로즈업은 화면을 가득 채웁니다.
8. **줌의 두 문법.** 기본은 와이드 ↔ 2.5배 하드 컷(Notion)으로 하고, 커서 동작을 따라갈 때만 15f ease-in-out 연속 푸시(1.0 → 1.9배, Marker)를 씁니다.
9. **극단 클로즈업 타이핑 + 캐럿 추적 카메라 (Notion).** 글자 높이 26%H, 초당 12자, 캐럿이 85% 지점에 닿으면 카메라가 따라갑니다.
10. **요소 하나를 매치컷·레이아웃 모프로 다른 맥락에 옮기기 (Marker 버튼 → 위젯, Jam 팝업 → 티켓).** 우리 영상에서는 질문 카드가 관리자 화면에서 고객 위젯으로 넘어가는 장면에 씁니다.
11. **커서가 주인공 (Marker, Notion).** 외곽선 있는 큰 화살표가 머무름 → 클릭(축소) → 리플 순서로 움직이고, 필요하면 도구로 모양이 바뀝니다. 경로는 곡선, ease-in-out입니다.
12. **스피너 대신 상태 글자 (Notion "Thinking ●●● → Crafting").** AI 처리 대기를 가운데 놓인 한 줄 상태 글자와 롤링 목록으로 대신합니다. 이어서 토스트 + 디포커스(Marker)로 비트를 닫습니다.
