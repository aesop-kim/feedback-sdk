## 2. 추천 스타일
**"토스식 라이트 미니멀 + 녹화 화면 대신 다시 그린 UI"**

- **배경과 색:** 오프화이트·회색 배경(Cursor, Notion, 토스)에 강조색은 브랜드 블루 하나만 씁니다.
- **UI는 화면 녹화 대신 실제 React 컴포넌트를 레이어로 렌더링합니다.** 줌은 녹화본 확대가 아니라 카메라 이동으로 처리합니다(Notion, Linear).
- **한국어 카피는 한 화면에 한 문장**, 토스 미니앱식 목록 롤링을 씁니다.
- **문제 제기는 Marker.io 방식:** 카드가 쏟아지고 배경색이 반전됩니다.
- **AI 처리 표현:** Attio의 "생각 중…" 타이포에 Loom식 패널 슬라이드인을 더합니다.
- **사운드:** 클릭·팝 효과음을 UI 등장 프레임에 맞춥니다. 인상을 가장 쉽게 끌어올리는 요소입니다.

## 3. 스토리보드 뼈대 (약 90초)
1. **훅 (0–8s):** 키네틱 타이포 "버그 설명, 또 글로 쓰고 계세요?" 메신저·메일 카드가 쌓이며 "재현 안 돼요", "어디요?" 말풍선이 겹칩니다. 배경이 회색에서 남색으로 바뀝니다. (Marker.io)
2. **문제 정리 (8–16s):** 큰 숫자 한 줄(예: "QA 이슈 1건당 왕복 4번"). 막대그래프를 쓴다면 Cursor처럼 우리 것만 진하게 칠합니다. *(숫자는 근거가 있을 때만)*
3. **위젯 등장 (16–28s):** 고객 사이트 위에 SDK 버튼이 팝 하고 나타납니다. 커서가 클릭하면 패널이 열리고 "녹화 시작". 화면 테두리가 빨간 녹화 링으로 그려집니다(Framer의 선 리빌을 응용).
4. **녹화 (28–40s):** 축소한 사이트 위로 커서가 움직이고, 음성 파형과 실시간 자막이 흐릅니다. 원형 PIP를 써도 좋습니다(Jam·Loom).
5. **AI 이슈 카드 (40–55s):** 녹화 타임라인이 접히면서 "분석 중…" 타이포(Attio). 이슈 카드 3장이 3D로 기울어진 채 차례로 날아와 쌓입니다(Linear식 기울임, 효과음 맞춤).
6. **장면 위 객관식 질문 (55–70s):** 캡처한 장면을 정지 화면으로 크게 보여주고, 해당 위치에 하이라이트 박스를 띄웁니다. 객관식 칩 A/B/C가 뜨고 커서가 B를 고르면 카드에 "확정" 체크 애니메이션이 붙습니다(토스식).
7. **관리자 해결 (70–82s):** 매치컷으로 같은 카드가 관리자 대시보드 목록으로 들어갑니다. 상태가 "새로 들어옴 → 진행 중 → 해결"로 바뀌고 고객 쪽 위젯에 "해결됐어요" 토스트가 뜹니다.
8. **엔드카드 (82–90s):** 토스 미니앱식 롤링 "녹화 한 번으로 / 재현 · 분류 · 질문 · 해결". 이어서 로고와 한 줄 카피.

## 4. 도구 선택

| 도구 | 적합도 | 메모 |
|---|---|---|
| **Remotion** | ★★★ 1순위 | 이미 있는 React 컴포넌트를 그대로 렌더링하고, `spring()`/`interpolate()`로 줌·패널·카드를 움직입니다. 3D 기울임은 CSS `perspective`와 `rotateX`로 충분합니다. 효과음은 `<Audio>`와 프레임 단위 `<Sequence>`로 맞춥니다. 코딩 에이전트와 같이 쓰기에도 좋습니다. |
| HyperFrames | ★★ | HeyGen이 공개한 HTML 기반 영상 렌더러(Apache 2.0, 2026년 공개)로, HTML/CSS 장면을 브라우저 캡처와 FFmpeg으로 MP4로 만듭니다. 이 환경에 관련 스킬(video-to-lesson)도 있습니다. 다만 React 컴포넌트를 바로 쓰는 면에서는 Remotion이 낫습니다. |
| Jitter | ★★ | Figma 프레임 기반 UI 모션을 빠르게 만들 수 있습니다. 1·8번 같은 타이포·엔드카드 장면만 따로 만들 때 유용합니다. 긴 영상 전체를 만들기에는 불편합니다. |
| After Effects | ★ | 품질 상한은 가장 높지만 하루 안에 혼자 90초를 만들기는 어렵습니다. |
| Rive | ★ | 인터랙티브 아이콘이나 로딩 마이크로 애니메이션용입니다. 영상 전체 제작에는 맞지 않습니다. |

**혼자서 하루 안에 현실적인 범위:** Remotion으로 8개 장면을 구성합니다.

- **오전:** 카피와 타이밍표를 확정하고, 컴포넌트를 영상용 정적 목업으로 고정합니다. 녹화 장면을 직접 재현하지 말고 짧은 실제 녹화 클립을 `<Video>`로 넣는 편이 빠릅니다.
- **오후:** 장면별 애니메이션과 효과음을 맞추고 렌더링합니다.
- **줄일 것:** 3D 카메라는 5번 장면 하나로 제한하고, 실사·일러스트(Superhuman, FacePay 스타일)는 하지 않습니다.
- **배경음악:** 저작권 프리 음원 한 곡의 BPM에 장면 전환을 맞추면 완성도가 크게 올라갑니다.
