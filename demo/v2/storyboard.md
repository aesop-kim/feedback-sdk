# v2 데모 영상 스토리보드

래티스 피드백 SDK 데모 영상 v2의 스토리보드입니다. 레퍼런스 4편에서 측정한 값(`frame-analysis.md`)을 그대로 옮겼습니다.

- **규격:** 1920x1080, 30fps, **104.0s (3120f)**, 25샷, ASL 4.2s. Marker.io는 4.4s, Notion은 2.9s입니다.
- **구조는 Marker.io를 따릅니다.** 문제 → 배경색 반전 → 소개 → 제품 흐름 → 결과 → 엔드 카드 순서입니다.
- **나머지 출처:** 한국어 타이포와 롤링 목록은 토스, 평면 UI 레이어와 카메라는 Notion, 녹화 → 이슈 흐름은 Jam에서 가져왔습니다.
- **내용:** 사실관계는 `demo/storyboard-final.md`와 `.screens/flow/*.png`, `.screens/qa-v2/ux/*.png`를 기준으로 했습니다.

## 0. 전역 규칙

### 색 (토스 디자인 시스템)

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| bg | `#F2F4F6` | 기본 배경 |
| surface | `#FFFFFF` | UI 레이어, 카드 |
| ink | `#191F28` (grey-900) | 본문 글자. 문제 구간(S03~S05)에서는 배경으로 씀 |
| accent | `#3182F6` (blue-500) | 유일한 강조색: 커서 리플, 포커스, 녹화 테두리, 선택, 새 음절 깜빡임 |
| 보조 | `#E8F3FF` (blue-50) · `#4E5968` (grey-700) · `#B0B8C1` (grey-400) · `#E5E8EB` (grey-200) | 칩 배경, 대사 자막, 롤링 비활성 줄, 헤어라인 |

- 그라데이션, 글로우, 반짝이, 그림자는 쓰지 않습니다. 카드는 1px `#E5E8EB` 테두리와 radius 20으로만 구분합니다.
- 실제 UI의 주황 "확인 필요" 배지는 영상에서 `#E8F3FF` 배경에 `#3182F6` 글자로 바꿉니다. 강조색을 하나만 쓰기 위해서이고, **실제 UI와 다른 유일한 부분**입니다.

| 토큰 | 굵기 / 크기 | 화면 높이 대비 | 근거 |

| T-TITLE | 700 / 112px, 자간 -2px | 10.4% | Notion 타이틀 11.6% |
| T-HEAD | 600 / 72px, 자간 -1px | 6.7% | 토스 고정 구절 6.7% |
| T-ROLL-ON | 700 / 104px, ink | 9.6% | 토스 포커스 줄 9.3% |
| T-ROLL-OFF | 500 / 72px, grey-400, 줄 간격 124px | 줄 간격 11.5% | 토스 줄 간격 11.4% |
| T-CAP (캡션) | 600 / 48px, ink(어두운 배경에서는 흰색) | 4.4% | 기준선 y=1004, 가운데, 한 줄, 26자 이내 |

**한 화면에는 한 문장만 둡니다.** UI 장면에서는 T-CAP 한 줄만, 타이포 장면에서는 그 문장 하나만 보여 줍니다.

### 모션 토큰

| 토큰 | 정의 | 근거 |
|---|---|---|
| E-OUT | cubic-bezier(0.16, 1, 0.3, 1) | 등장 4~7f ease-out |
| E-INOUT | cubic-bezier(0.65, 0, 0.35, 1) | 카메라 12~15f |
| SPR-POP | Remotion `spring({damping:15, stiffness:200, mass:0.8})`, 오버슈트 약 10%, 안정까지 약 20f | Marker 버튼 팝 |
| SPR-SOFT | `spring({damping:20, stiffness:170, mass:1})`, 오버슈트 약 2% | 카드, 패널 |
| WORD-POP | 단어마다 opacity 0→1 (1f), scale 1.08→1.00 (3f, E-OUT), **단어 간격 8f** | Marker 단어 팝 |
| SYL-TYPE | 음절마다 등장 2f 간격. 새 음절은 accent 색으로 4f 유지 → 3f 동안 ink로 선형 전환. 줄이 늘면 매 프레임 가운데 정렬을 다시 맞춤 | 토스 음절 타이핑 |
| SCRAMBLE | 이전 문구의 글자가 무작위 순서로 accent → 투명(글자당 2f)으로 사라지고, 새 문구 글자가 무작위 순서로 채워짐. 합계 12f | 토스 문구 교체 |
| ROLL | 고정 구절 + 오른쪽 세로 목록. 포커스 줄은 T-ROLL-OFF → T-ROLL-ON(4f, E-OUT). 줄 이동은 줄마다 ease-out, 간격은 15f에서 2f까지 가속 | 토스 롤링 |
| CAP-IN | T-CAP에 WORD-POP 적용, 단어 간격 4f. 샷이 시작하고 6f 뒤에 시작. 퇴장 애니메이션 없이 샷과 함께 컷 | |

### 카메라

- 모든 UI는 **다시 그린 평면 레이어(React 컴포넌트)**입니다. 스크린샷은 레퍼런스로만 쓰고 화면에 직접 올리지 않습니다.
- **기본 UI 레이어:** 1536x960 (1440x900 화면을 1.0667배), 화면 가운데, 사방 여백 60~192px입니다. Notion식 여백 프레이밍입니다.
- **연속 푸시:** 커서 동작을 따라갈 때만 쓰고, 15~20f, E-INOUT입니다. 최대 1.9배입니다.
- **하드 컷 줌:** 와이드 ↔ 클로즈업은 하드 컷으로 바꿉니다.
- **유지 중 드리프트:** scale +1.5%/3s, 선형입니다(Notion).
- **3D:** S03 플립 휩과 S18 질문 카드 비행, 두 곳에서만 씁니다.

### 커서

- **모양:** 화살표 52px(1배 기준, 4.8%H), 채움 ink, 흰 외곽선 3px. 카메라 배율에 따라 함께 커집니다.
- **이동:** 3차 베지어 경로이고, 직선에서 수직 방향으로 10~15% 휘어 갑니다. 길이는 `clamp(12f, 12f + 거리px x 0.012, 24f)`, E-INOUT입니다.
- **클릭:** 6f 머무름 → scale 1→0.86 (3f) → SPR-POP으로 1까지 복귀 → 리플(accent 3px 원, 반지름 0→36px, opacity 0.6→0, 10f E-OUT) → 4f 머무름.

### 오디오

- **음악:** 120 BPM 곡 하나. 한 박 = 15f, 한 마디 = 60f입니다. 레퍼런스 3편이 모두 118~120 BPM이었습니다.
- **박자 정렬:** 모든 샷 경계를 0.5s(한 박) 배수에 두었습니다. 그 밖의 박자 동기화는 하지 않습니다(레퍼런스도 하지 않음).
- **라우드니스:** 최종 통합 -16 LUFS를 목표로 합니다. 대사가 나올 때는 음악을 -8dB 낮춥니다.
- **대사:** `fixtures/demo-recording/narration.wav`의 구간을 그대로 씁니다(S10~S12).
